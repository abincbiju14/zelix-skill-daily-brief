# Daily brief

When the user asks for a daily brief or end-of-day summary:

1. Use only facts from this conversation and any tool results already shown.
2. Write 5-8 short bullets: done, in progress, blockers, next.
3. Keep it under 150 words. No invented numbers or meetings.
4. End with one suggested next action.
